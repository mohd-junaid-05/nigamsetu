# NigamSetu — The Pitch (One Paragraph)

India's Swachhata app handles 2.4 crore sanitation complaints with 93% resolution, yet CPGRAMS reports citizen satisfaction below 50% because "resolved" on a dashboard rarely means "fixed" on the ground. NigamSetu is not another complaint app -- it is an AI agent-powered accountability layer that closes the loop Swachhata leaves open. Citizens report roads, garbage, sewage, and school infrastructure failures through a mobile PWA with geotagged photos; a TypeScript AI agent with a defined toolset scores severity, clusters duplicates into weighted tickets, and verifies every claimed fix through before/after image comparison powered by vision models -- rejecting ghost closures automatically and generating escalation letters with full evidence trails when SLAs breach. Government operators see a live priority-ranked queue on a map dashboard, assign to the nearest facility via PostGIS KNN, and ask the agent natural-language questions about their ward data that it answers by looking up structured records rather than hallucinating. Built on Next.js, Clerk auth, Supabase Postgres with PostGIS and row-level security, and Google's Gemini as the agent's reasoning brain, NigamSetu turns the civic complaint pipeline from a black box into a transparent, verifiable, agent-enforced system -- because a complaint that enters a system and exits unverified is a ticket closed, not a problem solved.

## The Pitch (30-Second Version)

"Swachhata registers complaints. Nobody fixes what happens after they're ignored. I built an AI agent that verifies every claimed fix against the original photo, rejects fakes automatically, and drafts the appeal when the SLA breaches -- turning the complaint pipeline from a black box into a transparent, enforceable system."
